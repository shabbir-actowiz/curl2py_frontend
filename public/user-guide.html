Everything the app can do, in one place: pasting a cURL command, generating Python with curl_cffi, extracting data with the visual parsers, and chaining requests into a full pipeline.

01.2Account & cloud save

curl2py works entirely in your browser without an account, using local storage. Registering for a free account unlocks cloud sync.

Registration & login

Open Login from the top right corner. Register with email/password or continue with Google. Password registration requires a minimum of 8 characters and shows a real-time strength meter.

Forgot password flow

If you forget your password, reset it with a one-time code:

  1. Enter your registered email address.
  2. Receive a 6-digit OTP in your inbox and enter it before it expires.
  3. Set and confirm a new password.

Auto-saving

Once logged in, curl2py auto-saves your entire workspace — collections, snippets, parsers, code — on every change. A small "Saved" indicator appears in the bottom-right status bar. You can also force a save with the Save button in the top bar.

Collections & snippets

Work is organized hierarchically. A collection is a project folder; a snippet is one API request inside it.

Managing collections

  • Create: click the + icon next to "COLLECTION" in the sidebar.
  • Rename: click the collection name to edit it inline, then press Enter.
  • Delete: hover the collection to reveal the trash icon.

Managing snippets

Snippets live in the Input Panel as individual cards.

  • Naming: name every snippet (e.g. login, get_data). Left blank, a name is generated from the URL path. This name becomes the Python function name and filename (login.py).
  • Ordering: hover the left edge of a card for the grip handle, then drag to reorder. Order matters for Merge Scripts, which execute top to bottom.
  • Deleting: hover a card to reveal the × icon.

03.1Code generation

Paste standard cURL commands straight from devtools (Network tab → right-click → Copy as cURL) into the Input Panel's text area.

curl2py parses the raw string into structured data — URL, method, headers, cookies, body — then collapses the field to a clean one-line summary (e.g. GET https://api.example.com). Click the arrow to expand it again.

Static proxy configuration

The Proxy tab at the top of the Input Panel lets you enter a proxy URL (e.g. http://user:pass@192.168.1.1:8080). Checking "Enable Proxy" hardcodes it into the generated Python for every snippet in the collection.

Generating Python (curl_cffi)

Clicking Generate writes Python files into the Code Editor, built on curl_cffi instead of the standard requests library.

Why curl_cffi

Modern APIs fingerprint the TLS handshake (Cloudflare's JA3 checks, for example) to detect scraping scripts. Passing impersonate="chrome" makes the request mimic a real browser's handshake, so it isn't flagged.

Headers, cookies, and parameters are written into clean dictionaries. The body is sent as json= or data= automatically, based on the parsed Content-Type header.

Executing & responses

Clicking Run sends the generated Python to a sandboxed subprocess on the backend. A Python error, like a syntax error, is shown directly in the Output panel.

On success, the response is saved to a file (e.g. login_response.json) and shown in the Response Viewer, which includes:

  • Status bar: HTTP status, response time in ms, and content size.
  • Syntax highlighting: JSON and HTML rendered with color.
  • Interactive elements: clicking a JSON key or HTML element opens the Parser.

04.1Visual parsers

Pulling specific fields out of a large response by hand is slow. The visual parser automates it.

JSON parser in detail

Open Parser → JSON Parser. Four tabs:

TabFunction
SourceRaw JSON response. Click any key to generate its extraction path, or paste JSON manually with "Edit JSON" without running a live request.
PathsEvery selected extraction path. Define the output key — the Python variable name — and configure loops here.
Parser (Code)The generated parser.py, containing the dictionary traversal code.
OutputThe parser's result against the source JSON, in a JSON view and a table view for arrays.

JSON dot-notation arrays

Clicking a nested field computes an exact dot-notation path — clicking the price of the first item in an array gives data.items[0].price — and by default extracts a single scalar value.

Loop extraction vs. single value

A single value is easy, but usually you want every item in a list. That's loop extraction.

In the Paths tab, a path through an array (e.g. data.items[0]) populates a dropdown with loop candidates like data.items[*]. Selecting one tells the generator to write a Python list comprehension instead of a fixed index.

single_extraction.py
python 
# path: data.items[0].name
result["name"] = data["items"][0]["name"]
loop_extraction.py
python 
# path: data.items[0].name | loop: data.items[*]
result["name"] = [
    item["name"]
    for item in data["items"]
]

Click Optimize Parser to remove redundant loops and merge paths sharing the same array base.

HTML DOM & extractors

If the response is raw HTML, the Parser page opens the HTML Parser automatically, with two extraction methods:

1. Visual DOM picker

The HTML renders in a sandboxed iframe; hovering highlights elements. Clicking one computes the most resilient CSS selector and XPath available. In the Paths tab, choose what to pull from that selector:

  • text — the visible inner text.
  • html — the raw inner HTML.
  • attr — a specific attribute you name, such as href or src.

2. Script data extractor (JSON-in-HTML)

Frameworks like Next.js and Nuxt.js embed their state as JSON inside a <script> tag rather than the DOM. curl2py detects this automatically.

Click Extract JSON in the toolbar. It scans for known injection variables (__NEXT_DATA__, __NUXT__, window.initialState). Pick a block, click Save and Open JSON Parser, and it loads straight into the JSON Parser.

Database generation

Once the JSON parser extracts an array of data, open the DB Code tab to turn it into insertion scripts.

  • MySQL: uses mysql.connector. Inspects the parsed schema, writes a CREATE TABLE IF NOT EXISTS with matching SQL types (VARCHAR, INT, DECIMAL), and an executemany for bulk insert.
  • MongoDB: uses pymongo with a connection script and collection.insert_many() to dump documents directly.

Click Save DB Code to add db.py to your workspace.

05.1Pipelines

Pipelines chain requests together. Instead of copy-pasting a token from request A into request B, you declare the relationship and curl2py writes the Python to pass it automatically.

Variables & syntax

Variables use double curly braces inside the raw cURL text — in the URL, headers, or JSON body.

placeholder syntax
{{source_snippet_name.json_path|type}}
  • source_snippet_name — the name you gave the source snippet, e.g. auth_login.
  • json_path — dot-notation path to the value in that snippet's response, e.g. .data.token.
  • type (optional) — casts the value in Python: int, float, bool, string. Defaults to string.

Example usage:

request.curl
# injecting into a URL
curl 'https://api.example.com/users/{{auth_login.user.id|int}}'

# injecting into an authorization header
-H 'Authorization: Bearer {{auth_login.token}}'

Tutorial: 3-step chain

A real pipeline, end to end.

  1. Step 1 — the login request. Create a snippet named auth_login, returning {"session_token": "abc123"}.
  2. Step 2 — fetch profile. Create get_profile. In the cURL headers: -H 'Authorization: Bearer {{auth_login.session_token}}'. It returns {"user": {"internal_id": 994}}.
  3. Step 3 — update status. Create set_status, needing the token in the header and the user ID in the URL:
    curl -X POST 'https://api.com/users/{{get_profile.user.internal_id|int}}/status' -H 'Authorization: Bearer {{auth_login.session_token}}'

Merge scripts (main.py)

With placeholders set, Merge Scripts is what actually runs the chain.

Click Tools → Merge Scripts to generate an orchestration file, main.py, which:

  1. Creates a master dictionary, pipeline_context.
  2. Calls auth_login(), parses the response, and stores it at pipeline_context["auth_login"].
  3. Calls get_profile(pipeline_context=pipeline_context), which uses pipeline_utils.py to pull the token from the context and saves its own response back into it.
  4. Calls set_status(pipeline_context=pipeline_context), resolving both the token and the ID dynamically.

The result is a self-contained scraping script that needs no manual steps to run.

06.1Advanced features

Feasibility check

Use Feasibility for fast reconnaissance before building a parser or pipeline — to see whether an endpoint sits behind Datadome, Cloudflare, or needs a headless browser.

It sends a basic request and logs response size, status codes, and scans the HTML for anti-bot challenge keywords or JS-framework state injections, saving hours of manual debugging.

IP rotation system

Every snippet card has an "Enable IP rotation" checkbox. When checked, requests sent via Run route through the backend's internal, rotating proxy pool.

Proxy secrecy

Backend proxy IPs are confidential and are never written into the Python you see or download. They apply only when running code live through the curl2py UI.

Exporting (ZIP download)

curl2py builds production-ready Python projects. Click Tools → Download All to get a structured ZIP containing:

  • [snippet_name].py — the generated request functions.
  • [snippet_name]_parser.py — the data extraction logic.
  • main.py — the orchestration script, if Merge Scripts is active.
  • db.py — database insertion scripts.
  • pipeline_utils.py — helpers that resolve pipeline variables.
  • requirements.txt — run pip install -r requirements.txt (installs curl_cffi, pymongo, mysql-connector, etc.) before python main.py.

Issue tracking

Found a bug? Click your username in the top right and select Raise Issue.

Categorize it (Workspace, Parser, Execution), describe it, and attach logs or screenshots. Submitting gives you an issue ID, e.g. ISSUE-20260630-ABCDEF, which you can look up on the Track Issue page.
