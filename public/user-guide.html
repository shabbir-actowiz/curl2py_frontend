CurlCraft Comprehensive Guide

This is the official, unabridged documentation for CurlCraft. It covers every single button, feature, configuration, and advanced technique available in the application. Whether you are extracting a single JSON key or building a 10-step proxy-rotated data pipeline, you will find the exact details here.

1. Account & Cloud Save

CurlCraft functions entirely in your browser without an account using Local Storage. However, registering for a free account unlocks Cloud Sync.

Registration & Login

Access the Login page via the top right corner. You can register using an Email/Password or continue with Google. Password registration requires a minimum of 8 characters and includes a real-time strength meter.

Forgot Password Flow

If you forget your password, the reset process uses a secure OTP (One Time Password):

  1. Enter your registered email address.
  2. Receive a 6-digit OTP code in your inbox. Enter it within the time limit.
  3. Set and confirm a new password.

Auto-Saving

Once logged in, CurlCraft auto-saves your entire workspace (Collections, Snippets, Parsers, Code) every time you make a change. You will see a small "Saved" indicator in the bottom right status bar. You can also manually trigger a save by clicking the Save button in the top bar.

2. The Workspace

The CurlCraft workspace is divided into a robust, 4-panel architecture designed to keep input, output, and file management visible simultaneously.

Workspace Anatomy
Sidebar

File tree, collections, generated scripts.
Input Panel

cURL inputs, Proxy configuration, Snippet ordering.
Output Panel

Code Editor (Monaco), Response Viewer, Error Logs.

Top Bar Controls

The top bar is your command center. Every primary action is triggered here.

Collections & Snippets

Your work is structured hierarchically. A Collection is a project folder. Inside a collection are Snippets (individual API requests).

Managing Collections

  • Create: Click the + icon next to the "COLLECTION" header in the sidebar.
  • Rename: Click on the collection name in the sidebar to edit it inline. Press Enter to save.
  • Delete: Hover over the collection in the sidebar to reveal the trash can icon.

Managing Snippets (Requests)

Snippets live in the Input Panel as distinct cards.

  • Naming: At the top of each card is an input field. Always name your snippets (e.g., login, get_data). If left blank, the system auto-generates a name based on the URL path. The snippet name determines the generated Python function name and filename (login.py).
  • Ordering: Hover over the left side of a snippet card to reveal a grip handle. Click and drag to reorder snippets. The order is critical when using Merge Scripts, as they execute top-to-bottom.
  • Deleting: Hover over a snippet card to reveal an X icon in the top right to remove it.

3. Code Generation

Pasting cURL & Proxies

The Input panel contains a large text area for each snippet. Paste standard cURL commands directly from your browser's developer tools (Network Tab → Right Click → Copy as cURL).

The system automatically parses the raw string into structured data (URL, Method, Headers, Cookies, Body). Once pasted, the text area collapses to show a clean summary (e.g., GET https://api.example.com). You can click the arrow to expand it again.

Static Proxy Configuration

At the top of the Input Panel is a Proxy tab. Entering a proxy URL here (e.g., http://user:pass@192.168.1.1:8080) and checking "Enable Proxy" will hardcode this proxy into the Python scripts generated for all snippets in the collection.

Generating Python (curl_cffi)

When you click Generate, CurlCraft creates Python files visible in the Code Editor. We use the curl_cffi library instead of the standard requests library.

Why curl_cffi?

Modern APIs use TLS Fingerprinting (like Cloudflare's JA3 checks) to detect and block Python scraping scripts. curl_cffi allows the script to pass the parameter impersonate="chrome", which mimics a real browser's TLS handshake, bypassing these blocks flawlessly.

The generated code separates headers, cookies, and parameters into neat dictionaries. It automatically determines if a body should be sent as json= or data= based on the parsed Content-Type header.

Executing & Responses

Clicking Run sends the generated Python code to the backend. The backend spins up a sandboxed subprocess to execute the script safely. If the script throws a Python error (e.g., Syntax Error), it is displayed in the Output panel.

If successful, the API response is saved to a file (e.g., login_response.json) and displayed in the Response Viewer tab. The viewer includes:

  • Status Bar: Shows HTTP Status (200, 404, etc.), response time in milliseconds, and content size.
  • Syntax Highlighting: JSON and HTML are beautifully formatted and color-coded.
  • Interactive Elements: Clicking on keys in the JSON viewer, or elements in the HTML viewer, triggers the Parser system (detailed below).

4. Visual Parsers

Extracting specific data from massive API responses is tedious in raw code. The Visual Parser system automates this entirely.

JSON Parser in Detail

Navigate to Parser → JSON Parser. The interface has multiple tabs:

Tab Function
Source Displays the raw JSON response. Click any key to instantly generate a JSON path for extraction. You can also manually paste JSON via the "Edit JSON" button if you don't want to run a live request.
Paths Lists all selected extraction paths. Here you define the Output Key (the variable name in Python) and configure Loops.
Parser (Code) Displays the auto-generated parser.py file. This file contains the Python dictionary traversal code.
Output Shows the result of running the parser code against the source JSON. Includes a JSON view and a Table view for arrays.

JSON Dot-Notation Arrays

When you click a nested field, CurlCraft calculates the exact path using dot-notation. For example, clicking the price of the first item in an array generates the path data.items[0].price. By default, this extracts a single scalar value.

Loop Extraction vs Single Value

Extracting a single value is easy, but usually, you want to extract data for every item in a list. This is where Loop Extraction comes in.

In the Paths tab, look at the dropdown next to a path. If the path passes through an array (e.g., data.items[0]), the dropdown will populate with loop candidates (e.g., data.items[*]). Selecting the loop candidate instructs the code generator to write a Python List Comprehension instead of a direct index access.

Single Extraction CodePython
# Path: data.items[0].name
result["name"] = data["items"][0]["name"]
Loop Extraction CodePython
# Path: data.items[0].name | Loop: data.items[*]
result["name"] = [
    item["name"] 
    for item in data["items"]
]

Click the Optimize Parser button to clean up redundant loops and merge paths sharing the same array base.

HTML DOM & Extractors

If the API returns raw HTML, the Parser page automatically opens the HTML Parser. It provides two distinct extraction methods:

1. Visual DOM Picker

The HTML is rendered safely in an iframe. As you hover over the page, elements are highlighted. Clicking an element calculates the most resilient CSS Selector and XPath available.

In the Paths tab, you configure what to extract from that selector:

  • text: Extracts the visible inner text.
  • html: Extracts the raw inner HTML tags.
  • attr: Extracts a specific attribute (you must define which one, e.g., href for links, src for images).

2. Script Data Extractor (JSON-in-HTML)

Modern web frameworks (Next.js, Nuxt.js) don't rely on HTML parsing; they embed their entire state as a massive JSON object inside a <script> tag. CurlCraft detects this automatically.

Click Extract JSON in the HTML parser toolbar. The tool scans the page for known injection variables (__NEXT_DATA__, __NUXT__, window.initialState). Select the block you want, click Save and Open JSON Parser, and CurlCraft will isolate that JSON and load it into the JSON Parser for easy clicking.

Database Generation

Once your JSON parser is successfully extracting arrays of data, navigate to the DB Code tab to convert that data into database insertion scripts.

Select your target database from the dropdown:

  • MySQL: Generates Python code using mysql.connector. It inspects your parsed JSON schema, generates a CREATE TABLE IF NOT EXISTS statement with appropriate SQL data types (VARCHAR, INT, DECIMAL), and writes an executemany query for bulk insertion.
  • MongoDB: Generates Python code using pymongo. It creates a simple connection script utilizing collection.insert_many() to dump the JSON documents directly into the NoSQL store.

Click Save DB Code to add the generated db.py file to your workspace.

5. Pipelines (Connecting Requests)

Pipelines allow you to chain requests together. Instead of copy-pasting a token from Request A into Request B, you define a relationship, and CurlCraft writes Python code to pass the variable automatically.

Variables & Syntax

Variables are defined using double curly braces directly inside the raw cURL text area in the Input Panel. You can place them in the URL, Headers, or JSON body.

Placeholder Syntax Structure 
{{source_snippet_name.json_path|type}}
  • source_snippet_name: The exact name you gave the snippet that generates the data (e.g., auth_login).
  • json_path: The dot-notation path to the specific data point in that snippet's JSON response (e.g., .data.token).
  • type (Optional): Forces the variable to cast in Python. Options: int, float, bool, string. Defaults to string.

Example usages:

# Injecting into a URL:
curl 'https://api.example.com/users/{{auth_login.user.id|int}}'

# Injecting into an Authorization Header:
-H 'Authorization: Bearer {{auth_login.token}}'

Tutorial: 3-Step Chain

Let's build a real pipeline to understand how it orchestrates data.

  1. Step 1: The Login Request
    Create a snippet named auth_login. Assume it returns {"session_token": "abc123"}.
  2. Step 2: Fetch Profile
    Create a snippet named get_profile. In the cURL headers, write:
    -H 'Authorization: Bearer {{auth_login.session_token}}'
    Assume this returns {"user": {"internal_id": 994}}.
  3. Step 3: Update Status
    Create a snippet named set_status. It requires the token in the header, and the user ID in the URL. Write:
    curl -X POST 'https://api.com/users/{{get_profile.user.internal_id|int}}/status' -H 'Authorization: Bearer {{auth_login.session_token}}'

Merge Scripts (main.py)

Once your placeholders are set, how do you actually run the 3-step chain from the tutorial above? You use Merge Scripts.

Click Tools → Merge Scripts. CurlCraft generates an orchestration file named main.py. This file:

  1. Creates a master dictionary called pipeline_context.
  2. Calls auth_login(), parses its JSON response, and saves it to pipeline_context["auth_login"].
  3. Calls get_profile(pipeline_context=pipeline_context). The generated code for get_profile uses the pipeline_utils.py helper to extract the token dynamically from the context dictionary. It saves its own response to the context.
  4. Calls set_status(pipeline_context=pipeline_context), extracting both the token and the ID dynamically.

This creates a completely autonomous Python scraping script that requires zero manual intervention.

6. Advanced Features

Feasibility Check

The Feasibility tool is used for rapid reconnaissance. Before building complex parsers or pipelines, you need to know if an endpoint is protected by Datadome, Cloudflare, or requires a headless browser.

Clicking Feasibility generates a script that sends a basic request and logs critical metadata to the console. It checks the response size, status codes, and scans the HTML for known anti-bot challenge keywords or JS-framework state injections. It saves you hours of debugging.

IP Rotation System

On every snippet card in the Input Panel, there is an "Enable IP rotation" checkbox. When checked, requests executed via the Run button are routed through the backend server's internal, rotating proxy pool.

Proxy Secrecy

The backend proxy IPs are highly confidential. To prevent leaks, these proxies are never injected into the generated Python code that you see or download. They only apply when executing code live through the CurlCraft UI.

Exporting (ZIP Download)

CurlCraft is designed to build production-ready Python projects. To move your work to your local machine or server, click Tools → Download All.

This generates a structured ZIP archive containing:

  • [snippet_name].py — The generated request functions.
  • [snippet_name]_parser.py — The data extraction logic.
  • main.py — The orchestration script (if Merge Scripts is active).
  • db.py — Database insertion scripts.
  • pipeline_utils.py — The helper functions required for variables to resolve.
  • requirements.txt — Ensure you run pip install -r requirements.txt (installs curl_cffi, pymongo, mysql-connector etc.) before running python main.py.

Issue Tracking System

If you encounter a bug, the app has a built-in issue tracker. Click your username in the top right and select Raise Issue.

You can categorize the bug (Workspace, Parser, Execution), write a description, and attach logs or screenshots directly. Upon submission, you receive an Issue Tracking ID (e.g., ISSUE-20260630-ABCDEF). You can use the Track Issue page to check the status of your ticket.
